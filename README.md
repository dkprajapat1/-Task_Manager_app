# Task Manager App

A simple full stack Task Manager app with basic CRUD functionality.

## Tech Stack

* React (Vite)
* Node.js, Express
* MongoDB (Mongoose)

## Setup

### Backend

```bash
cd backend
npm install
npx nodemon server.js
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

## API Endpoints

* GET `/` → Get all tasks
* POST `/task` → Add task
* PATCH `/edit_task/:id` → Update task
* DELETE `/delete/:id` → Delete task
